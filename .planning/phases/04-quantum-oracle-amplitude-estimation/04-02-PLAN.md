## Decisions this plan implements

- **PD-17 (locked, research)**: vendored numpy MLAE. Likelihood sum_k [h_k log sin^2((2k+1) theta) + (n_k - h_k) log cos^2((2k+1) theta)] with 0 log 0 = 0; grid `np.linspace(EPS, pi/2 - EPS, grid_size(ks))` with `grid_size = max(10000, int(pi / 2 * 1000 * 2 * max(ks)))` and `EPS = 1e-15` (qiskit-algorithms' conventions, so the QAE-01 equality is exact); golden-section refinement inside the neighbouring grid points, accepted only if not worse; records sorted before evaluation; Fisher standard error se_a = sin(2 theta) / sqrt(sum 4 n_k (2k+1)^2); cost N_A = sum shots (2k + 1) from our own records (Suzuki et al. 2020, eq. 11), never qiskit's num_oracle_queries. Headline schedule `exponential_schedule(M) = [0] + [2 ** j for j in range(M - 1)]`; `linear_schedule(M) = list(range(M))` for comparison. `MAX_POWER = 1024` bounds the grid (DoS guard).
- **PD-18 (locked, research; `costly`)**: one runner interface `run(ks, shots) -> list[PowerResult]` (the analytic runner has no circuits, so a counts-based interface cannot serve it). `AnalyticRunner(p, rng)`; one generic `BackendRunner(backend, problem, ...)` with the backend injected (Aer from tests/scripts, BasicSimulator on Qollab's Built-in); `IonQRunner(backend, problem, ideal_mode)` sends one bare circuit per run. Aer and BasicSimulator are constructed only under `tests/` and `scripts/`.
- **PD-20 (locked, orchestrator; `costly`)**: IonQ record schema `{"schema": "neutron_qae.ionq_record", "schema_version": 1, ...}` printed as one `IONQ_RECORD=` line per Qollab run (04-03) and stored in `data/ionq_runs.json` (literal path `IONQ_RUNS_FILE` in runners.py); records are validated on load; noisy runs (`ideal_mode = "none"`) are kept as `sampled: false` and excluded from the MLAE (Open Question 3); `sampled` is read from the backend's actual `options.noise_model` after the ideal-mode step, never from the form value alone.
- Pitfall 6 (research): with any `noise_model` other than "ideal" set through `set_options`, qiskit-ionq builds counts as round(p shots); the same holds for the run kwarg. Only `set_options(noise_model="ideal")` counts are Binomial samples.
