**1. [Rule 1 - Robustness] `lines_of` opens ENDF files with `encoding="latin-1"`**
- **Found during:** Task 2
- **Issue:** The prototype's `open(path)` used the locale default encoding. A stray non-UTF-8 byte in an untrusted ENDF file could then crash the parse.
- **Fix:** Added an explicit `encoding="latin-1"` (every byte decodes, and numbers are still parsed only by `fnum`). `mubar` now takes the parsed record rather than a path, so each file is parsed once, as the plan's `isotope_values` requires. The function bodies are otherwise copied verbatim.

- **Committed in:** bebefe3

**2. [Minor] SS316 atom densities for C, P and S added to the doc**
- RESEARCH listed only six SS316 elements. The doc lists all nine, printed from `atom_densities`, so the composition and densities match.
