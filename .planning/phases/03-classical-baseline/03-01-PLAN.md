- **PD-08 (locked, research; `costly`)**: the random-source protocol is one structural method, `random(size) -> float64 array of shape (size,) in [0, 1)`. A numpy `Generator` satisfies it unwrapped. `as_source(None | int | np.integer | SeedSequence | source)` is the only place a Generator is built; `draw()` validates shape and range. Phases 4-6 call this seam.
- **PD-09 (locked, research)**: the continuous engine is Woodcock delta tracking, vectorized over histories in chunks of 2^16, majorant `max(spec.front.sigma_t, spec.back.sigma_t)` (the WHA transport-corrected value under the default model), cross sections taken from `spec.front`/`spec.back` (never from `Kernels`), material looked up at the tentative collision site with the half-open rule, exit tested before collision, corner ties assigned to the x face like `kernels.py`, isotropic 2D scattering phi = 2 pi u, int64 count tallies with binomial SEs computed once, `max_iter` guard.
- **PD-11 (locked, research + orchestrator)**: validation compares sums only: `within(0)` with e^{-tau}, `within(1)` with T1, the at-most-one-collision row histogram and the first-collision column histogram; never the full transmission against T1 and never individual table entries (WR-07). Tolerances: fixed seeds, |z| < 4, chi2 < dof + 5 sqrt(2 dof).
- **PD-12 (locked, research)**: reproducibility contract = same source state + same n + same chunk + same numpy version and platform; the draw order is documented in the docstring; a different chunk changes the histories and that is stated and tested.
- **PD-14 (locked, orchestrator)**: repo integration: no edit to `main.py`, `neutron_qae/__init__.py`, `kernels.py`, `exact.py`, `problem.py`, `nuclear_data.py`, `smoke.py`, `data/`, `tests/golden/`; no new dependency; no `data/` file.
